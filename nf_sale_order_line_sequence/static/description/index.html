Automatic Line Numbers on Sale Orders
  • Each sale order line displays a sequence number for easy identification and reference.
Dynamic and Auto-Updating
  • Line numbers are automatically updated when lines are added, deleted, or reordered - no manual adjustment required.
Supports Print Reports
  • Optionally display line numbers on printed purchase order and sale order reports for professional documentation.
Compatible with Odoo Standard Views
  • Works seamlessly with Odoo’s native Sale and Purchase modules without altering their core logic.
Works Out of the Box
  • No configuration or setup required - simply install and enjoy improved clarity in your order lines.
