⌨️ Keyboard Shortcuts Configuration

Configure custom keyboard shortcuts for Odoo to boost your productivity!

🚀 Key Features

  • Create personal shortcuts for your workflow
  • Administrators can set global shortcuts for all users
  • Context-aware shortcuts (form, list, kanban views)
  • Model-specific shortcut configurations
  • Automatic conflict detection and warnings
  • Import/Export shortcut configurations
  • Pre-configured common shortcuts included

📋 Default Shortcuts

The module comes with these pre-configured shortcuts:

Enter → Move to next field
Ctrl + Enter → New line in text fields
Ctrl + S → Save record
Ctrl + N → Create new record
Ctrl + E → Edit record
Ctrl + D → Duplicate record
Ctrl + F → Focus search
Escape → Close dialog

🎯 Use Cases

Data Entry: Use Enter to quickly navigate between fields instead of clicking

Text Editing: Use Ctrl+Enter for new lines in descriptions and notes

Quick Actions: Save records with Ctrl+S without reaching for the mouse

Navigation: Jump to search with Ctrl+F in list views

👤 For Users

  1. Go to Keyboard Shortcuts → My Shortcuts
  2. Create your personal shortcuts
  3. Configure key combinations and actions
  4. Enable/disable shortcuts as needed
  5. Export your configuration for backup

👨‍💼 For Administrators

  1. Access Keyboard Shortcuts → Configuration
  2. Create global shortcuts for all users
  3. Manage shortcut actions
  4. Monitor and resolve conflicts
  5. Set up company-wide productivity standards

⚙️ Configuration Options

  • Scope: Personal or Global
  • View Type: All, Form, List, Kanban, Calendar, Pivot, Graph
  • Models: Apply to specific models or all
  • Modifiers: Ctrl, Alt, Shift, Meta/Cmd keys
  • Actions: Navigation, Form actions, Text input, Record actions

🔒 Security

Two security groups are provided:

  • Keyboard Shortcuts User: Create and manage personal shortcuts
  • Keyboard Shortcuts Manager: Manage all shortcuts and create global ones
