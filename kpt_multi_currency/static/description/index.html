KPT Multi-Currency Performa Invoice

Manage Sale Orders with Multiple Currencies

Features

  • Automatic currency selection based on customer's pricelist or currency
  • Manual currency change option in sale order/quotation screen
  • Currency field visible and editable in sale order form view
  • Automatic price recalculation when currency changes
  • Currency grouping in search/filter options
  • Currency displayed in sale order tree view
  • Seamless integration with invoice generation

How to Use

  1. Install the module from Apps menu
  2. Create or edit a sale order/quotation
  3. Select a customer - currency will be set automatically from customer's pricelist
  4. You can manually change the currency field if needed
  5. Product prices will be recalculated based on selected currency
  6. When creating invoice, the currency will be carried forward
